# nesiddo note記事 通読記録

## 結論

2026-09-05に、プロフィールで公開されていた全20記事を本文の末尾まで通読しました。

MAGATU TEMPO FORGEへ直接関係する最重要事項は次のとおりです。

- `timing(時刻,BPM,第3引数);`の第3引数は、厳密な拍子記号ではなく小節線の頻度を制御する値として説明されている。
- BPMは音楽テンポだけでなく、停止、逆走、急加速、バウンド、ダミーノーツなどの表示・演出速度にも使われる。
- 完全なAFFでは通常グループの先頭に`timing(0,...)`を置く。
- 既存のarc／traceの途中へ`timing`を追加すると表示が崩れる可能性がある。
- `AudioOffset`を0にするため音源へ無音を足す方法は、譜面時刻の理解、数字のずれによる誤解防止、譜面の整理に有効。初期実装では見送るが、任意機能の候補として残す。

## 記事別の確認内容

1. **ArcCreateの使い方講座**
   ArcCreateの概要とモバイル版へのパッケージ導入手順。譜面製作者向け部分は記事内でも未執筆と明記されており、AFF仕様の根拠にはならない。

2. **timinggroupについて理解しよう！（anglex & angleyの解説付き）**
   timinggroupを独立したBPMを持つレイヤーとして説明。`noinput`、`anglex`、`angley`の例を掲載。ArcadeZero v4では属性構文が異なるという注意があり、本家形式と派生形式を混ぜない必要がある。

3. **Arcaea公式のコンセプト配置**
   作曲者・コラボ作品ごとの特徴的配置を整理した記事。AFF構文より譜面デザインの資料。動画依存部分は今回未検証。

4. **本家scenecontrolを理解しよう！**
   `hidegroup`、`trackhide`、`trackshow`、`enwidencamera`、`enwidenlanes`、`redline`、`arcahvdistort`、`arcahvdebris`を説明。後半にArcadeZero独自形式との差異が明記されている。

5. **ノーツのバウンドギミックについて**
   負BPMから正BPMへ移る区間の積算移動量を釣り合わせる必要を説明。段階的な`timing`列の具体例がある。

6. **ダミーノーツの置き方（2022年版）**
   極端な負BPMを使う方法と`hidegroup`を使う方法を比較。本家形式とArcadeZero v4の透明度指定が逆方向である点も説明されている。

7. **Arcaeaの譜面レギュレーションについて**
   公式発表ではなく観測上の規則であると記事自身が断っている。TEMPO FORGEに重要なのは、arc／traceの途中で`timing`を変更すると表示が崩れる可能性があるという記述。

8. **【Mac/Linux向け】創作譜面をArcaoidに出力する方法**
   `.arcaoidlevel`の手作業パッケージ化。AFFのタイミング仕様には直接関係しない。

9. **ダミーノーツの置き方（2021年版）**
   曲後方に置いたノーツを極端な負BPMで手前へ運ぶ旧方式。2022年版に整理・更新されている。

10. **Summer Vocaloid Pack告知**
    共同制作企画の紹介。技術仕様に関する新情報はない。

11. **cameraの使い方**
    9引数のcamera構文、移動・回転軸、`s`、`qi`、`qo`、`l`、`reset`を具体例付きで説明。今回のテンポ出力には直接使用しない。

12. **AudioOffsetを0にする方法**
    音源先頭へ一小節分の無音を加え、Music TimeとChart Timeを揃える方法。弱起への言及もある。曲を開始したい譜面時刻までの無音長をテンポから逆算してWAV先頭へ連結する運用は、ユーザー自身にも実績がある。初期実装では見送るが、恒久的に不採用とはしない。

13. **創作譜面をArcaoidに出力する方法**
    Arcaoid向けパッケージ出力手順。AFF構文には直接関係しない。

14. **Arcaoidに創作譜面を導入する方法**
    iOS／Androidへの導入手順。AFF構文には直接関係しない。

15. **速度変化ギミックの作り方**
    最重要記事。停止、滑らかな速度変化、ほぼ停止、逆走、急出現、小節線調整を説明。第3引数は小節線の頻度で、BPMとの比率が表示間隔へ影響することを具体例で示している。timinggroup内では小節線が表示されないとも説明されている。

16. **.affの読み方について**
    `AudioOffset`、区切り線、timing、tap、hold、arc、arctapの基本構文を説明。第3引数を「小節線の頻度」と明記し、`timing(0,...)`を必須としている。掲載された一部arctap例には閉じ括弧が欠けているため、例文をそのまま仕様とはみなさない。

17. **Arcade（派生含む）の使い方**
    Timing Listを「時刻、BPM、小節線の頻度」と説明。AudioOffset、グリッド、基本ノーツと編集操作の解説。

18. **譜面を作るために必要な楽曲フォルダの作成**
    `base.wav`／`base.ogg`／`base.mp3`と`base.jpg`による制作フォルダ構成。AFFタイミング仕様には直接関係しない。

19. **Arcaea Fanmade（創作譜面）の作り方一覧**
    全記事の目次とコミュニティ案内。

20. **Arcade(派生含む)のダウンロード**
    ArcadeZero、Arcade-plus、Alt Arcadeの紹介。記事自身がリンク先は最新版とは限らないと注意しているため、現行版の根拠には使用しない。
