創作譜面をArcaoidに出力する方法

Source: https://note.com/nesiddo/n/n2fc19c0d8a07

Published: 2021-06-08T11:06:50.000+09:00

創作譜面を作り終わってArcaoidでプレイしたいよって人向けの内容です。
割と簡単なのですぐに終わります。
Arcaoidの使い方は
https://note.com/nesiddo/n/n72edfb405a80

1.ARCAOIDCHARTERのダウンロード

このリンクからダウンロードします。（mega）
https://bit.ly/3g0rYKl

2.ARCAOIDCHARTERの出力方法

Arcadeと同じくUnityなので、同じノリで解凍し起動してあげればokです。

そしてArcaoid Charter.exeを起動します。

この画面も自分のお好みの画面サイズや画質に設定してください。

起動し、Arcadeの要領で譜面を読み込みます。

読み込んだら右上のタイトルとコンポーサー(作曲者名)と難易度(数字)を打ち込みます。

打ち込んだら右下のExportをクリックします。

この画面が出たら、
イラストレーター(わからなければ???など何か入力)
譜面制作者
BPM
光サイド/対立サイド
背景の有無※
を設定します。

全て設定し終わったら、Confilmを押すと曲ファイルの中に〇〇.arcaoidlevelが出力されます。


 ​※背景を付ける場合は、自定义背景(User Backgrounds)に背景画像を入れて、右上の服マークからRefreshを押してから背景を変えてから、
User Background?にチェックを入れます。


3.終わり！

完成した〇〇.arcaoidlevelはzip形式なので拡張子を.zip変えれば開くことができます。

次はArcaoidに導入します。頑張りましょう。
