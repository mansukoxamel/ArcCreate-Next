0.はじめに

譜面を作るために必要な楽曲フォルダの作成
https://note.com/nesiddo/n/n8c6a1c92ef04

↑の続きです。まだ読んでない方はリンクから
今回はArcadeZero_2.0Alphaを使っていきますが他のでもほとんど同じです。

1.曲を読み込もう

最初はこんな感じになってると思います。まず右上の？をクリックします。

ファイルを選択して...(ここで選択するのは曲の入ったファイルです。)

読み込まれました！

2.タイトルをつけよう

右上のNameとComposerを書きましょう。左クリックをしてキーボードで打てば打ち込めます。難易度がもう決まっているのなら、Difficultyを打っても大丈夫です。

出来ました！

3.曲に合わせたスキンを設定しよう

右側にある服のボタンをクリックすると...

なんかでてきました。一つずつ解説するとめんどk...長くなるので、大まかに言うと、光サイドの曲はLight(white)、対立サイドはConflict(Black)とかにしておけばいいです。
MA LineはMemory Archiveにある左右の光の線の奴ですね（語彙）
Backgroundは背景です。お気に入りのを選びましょう。
(蛇足ですが、User Backgroundに自分のお気に入りの背景を入れることでArcadeの背景を自分の画像に設定することもできます。画像比1280:960推奨)

適当にいじってると何となくわかると思います。

4.BPMを設定しよう

超大事です。
まず自分の作りたい難易度を確認しましょう。FTRなら初期設定でOK。
BYD譜面なら右上の四色ボタンの一番右をクリックしましょう。
Difficultyが赤くなっていればOK

右側のTiming Listを押してみましょう。（もう一回押すと閉じます）

なんかでました。この数字列を解説すると、

任意のタイミング,BPM,小節線の頻度

ということです。任意のタイミングは画面上に表示されているTimingのことです。
曲のBPMは各々調べてもらって、初期BPM値は100ですが今回の曲は87.5なのでそのように変更します。
変更したら、左のSaveを押してセーブをして、右上の四色から左から三番目の赤ボタン（BYD譜面は一番右）を押して再ロードします。

これやらないとBPMずれたりするので気を付けてください。またしれっとセーブのやり方を説明しましたがこれも重要なので覚えてください。

＊補足
このtimingのBPMをマイナスにすると逆走ができます。

5.オフセットを設定しよう！

まずはオフセットの設定！画面中央で右クリックをしたままドラッグしてClick to Createの上で右指を離します。同じ要領でGridlineを押して離します。

こうすることで四本の線が見えてきました！

さぁあとは曲が始まるところを見つけて、そこのタイミングを記憶しましょう。（再生は左上のPAUSEからできます。またQキーでも可能）

今回は514で始まりそうだったので上のAudio Offsetに514と入れます。

これでOK!!!

6.いよいよ創作譜面を作っていこう！

さあ、いよいよ作れます。まずはここまでお疲れさまでした。
Tap
まずはTap Noteの配置です。右クリックをしたままドラッグしてTapの上で右指を離します。そして譜面の上で右クリックするとノーツが設置できます！いい感じのタイミングでいい感じに設置していきましょう。

Hold
Holdも同じ要領で切り替えができます。右クリックをしたままドラッグしてHoldの上で右指を離します。
そして、Tapと違うのはホールドは設置するためにクリックした後奥行きを設定できます。マウスを奥にドラッグすることでHoldが伸びます

Arc
こいつが一番手ごわいです。同じ要領でArc・を選びます。

こんな画面になりましたね。
......えっ？黄色の線が違う？
説明し忘れてましたね！右の上から二番目の水色のボタンをクリック！

この数値はグリッド（黄色の線）の配置の設定です。意味わからんと思いますが大丈夫。初期設定でもいいのですがおすすめはこれです。

X　-0.5>1.5/0.125
Y　-0>1/0.125;0.5

さて話に戻って、クリックして設定すると、またホールドと同じ要領で奥行きが設定できます。その次、マウスを動かすと終点がどの位置かを設定できます。

なんかよくわからんタブが出てきました。Timingは始点、Endは終点、Start Pos,End Posは始点、終点のポジションです。Colorは色ですね。
IsVoidにチェックを入れると細くなりましたね！トレースノートのことですね！

じゃあTypeって...?どうやらいくつか種類があるみたいです...

ここで注意！！！！！

Arcaeaの譜面配置にはレギュレーションがあります！
アーク配置には配置していい位置ダメな位置があります。
（FTRのレギュレーション）

引用：MichikoIku様

（X座標,Y座標）です。この緑の範囲で設置した方がいいです。

BYD譜面ではもうちょい範囲が広がりますが最近はレギュレーションがあってないようなものなので、割と自由に設置できます。いい塩梅で設置しましょう。

ArcTap

いつもの要領で、ArcTapを選ぶとスカイノートが設置できます。
これは、トレースノートの上に設置できます。逆に言えばそれがないとできないので注意。また二回押さないと設置できなかったりすることがあるので気を付けましょう。

削除

ノーツを選んで右クリック長押しでDeleteを選択またはノーツを選んでDeleteキーで一発で消せます。

7.その他の機能や設定

ファイルマーク
右にあるファイルマークは、この譜面のデータが入っているフォルダを一発で開きます。発展的なことをするときに便利です。

メガホンマーク
これは音の大きさの設定ができます。

Chart Audioは音楽の大きさ。
Judge Audioは効果音の大きさです。

中/Aマーク
中国語か英語かを選べます。好きな方をどうぞ。

Speed
上にあるSpeedは譜面の流れる速さを設定できます。BPMとは関係ないです。
値を大きくすれば...

値を低くすれば...

密です。完成して録画するときは130~をおすすめします。

Sync File
これは、セーブすると自動でロードが入ります。まぁバグらせたくなければON推奨ですが（ロードすることで変な挙動を起こしにくくなる）時間が数秒失われるのでイライラする人はいるかも...
個人の好みでON/OFFしてください。

その他
そのほかはあんま機能知らなくても全然大丈夫です。ちなみに筆者もよくわかってないのあります。知りたいときは適当に触って理解してください。僕は知らなくても生きていけました。

以上のことを踏まえて基本事項は終了です。
発展的な内容（スピード変化、timing groupの使用、cameraの使用等）は別記事で紹介します。
頑張っていい感じな譜面を作ろう！！！！

8.コツとかやったらダメな事とか

譜面作るのマジで時間かかります。ほぼやる気との勝負みたいなところあります。
制作時間短縮のコツとして、

一回ノーツ選択（右クリック長押し）でExitしたあと、ノーツ選んでまた同じく右クリック長押しするとCopyとかmirrorがあります。
文字通りなのでうまく活用していきましょう。

また、Ctrlを押したままノーツを押すと複数選択ができます。一気に消したりコピーしたり反転させましょう。

そのほかにも、

ショートカットキーを使うと楽です。

右下Hotkeyからいつでも見れます。特にCtrl+Zは覚えておくと人生得します。

他にもFキーを使ったショートカットがあります。

※Click to Createしている前提
F1…アークのvoidの切り替え
F2…アークの色の切り替え(緑には非対応)
F3…アークのTypeを対のTypeにする(S↔B、Si↔So、SiSo↔SoSi、SiSi↔SoSo)
F4…アークのTypeをひとつずつ変更する(S→B→Si→So→SiSi→SiSo→SoSi→SoSo→S…)
F5…好きなノーツを選択してマウスのホイールを押すと始点、終点のタイミングそれぞれをずらすことが出来る
F6…好きなノーツを選択してマウスのホイールを押すと位置を動かせる。アークだと始点、終点の位置を変更できる

Ctrl+T…なんかよく分からないけど面白い。
Ctrl+R…範囲選択。すごい便利。
