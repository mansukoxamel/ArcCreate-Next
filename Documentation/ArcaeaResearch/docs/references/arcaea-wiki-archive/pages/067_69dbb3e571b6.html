各種機能

メインメニュー

Arcaeaを起動するとまず最初に表示される画面です。ハブのような役割をもち、この画面を通して様々な機能にアクセスできます。

  • 「Music Play」：楽曲選択画面に移行します。
  • 「Story Mode」：ストーリーにアクセスできます。
  • 「Course Mode」：コースモードにアクセスできます。
  • 「Network（地球儀のマーク）」：フレンドの追加と確認、プロフィールカード、クラウド同期、アカウント管理、コードの利用にアクセスできます。
  • 「More」：チュートリアル、言語設定、ダウンロードの管理、実績にアクセスできます。*1
  • 「World」：ワールドモードにアクセスできます。
    • スタミナ残量は右下に、(開催されている場合)イベントの残り日数が右上に表示されます。
    • 「続きへ」を押すと進行中のマップに直で飛ぶことができます。
  • 「ビギナーミッション（書類のマーク）」（Worldの右上）：ビギナーミッションにアクセスできます。全てのミッションを達成すると表示されなくなります。
  • 「UPDATE」：最新のアップデートで実装されたコンテンツが表示されます。
  • 「⇄（変更する）」：カスタマイズができます。

画面上部に表示される以下の機能は、プレイ中以外のほとんどの画面で表示されます。

  • ユーザー名
    • ログインしていない場合は「ゲスト」と表示されます。
    • ユーザー名はプロフィールプレートに表示されます。プレートはコースモードやArcaea Onlineで入手することができます。
      • コースモードで獲得したプレートのうち、一番難易度が高いものが自動で設定されます。Arcaea Onlineにて任意のプレートを設定することが可能です。
  • 選択しているパートナー
    • パートナーアイコンをタップするとパートナー選択画面に移行します。
  • ポテンシャル
  • 順位
  • 設定
  • 保有している欠片・メモリー
    • メモリー欄をタップするとメモリー購入画面に移行します。
 

ユーザー登録・ログイン

※オンラインでプレイするには最新バージョンのアプリが必須です。
※複数人でのアカウント共有を防ぐため、1アカウントでログインできるデバイスは2台までです。3台目以降はログイン履歴の古い順から自動でログアウトされます。
ユーザー登録をすると、以下の機能が利用できるようになります。

  • フレンド機能
  • プロフィール
  • クラウド同期
  • アカウント管理
  • コードの利用
  • ワールドモード
  • ビギナーミッションの報酬受け取り
  • ポテンシャル
  • Link Play
  • メモリーの購入
  • 楽曲ランキングへの登録
  • Arcaea Onlineの利用　など

ユーザー登録をしなくても、「Arcaea」パックの楽曲のうちワールドモードでの解禁が不要なものは遊ぶことができます。
しかし、数が少ない上に難易度の低い曲が多いため、Arcaeaを楽しみたいのならユーザー登録を強くお勧めします。

[画像: ユーザー登録]

「メインメニュー」>「Network（地球儀のマーク）」>「登録」と進み、利用規約をよく読んで下さい。同意すると画像のような入力画面が表示されるので、必要事項を記入して「アカウントを作成」を押せば登録完了となります。
この際、すでに使われているユーザー名は使用できません。また、ユーザー名は公式サイトから変更可能です（変更1回につき100メモリー）。
登録が完了すると以降は自動でログインされます。基本的にログイン状態は保持されますが、ログアウト状態になった場合は「メインメニュー」>「Network」>「ログイン」からログインし直す必要があります。

 

フレンド

※ユーザー登録・ログインが必要です。
[画像: フレンド追加]

フレンドになることで楽曲選択画面のフレンドランキングに表示されるようになります。
「メインメニュー」>「Network（地球儀のマーク）」>「追加」と進み、相手のIDを入力して下さい。

  • IDはプロフィールカードのユーザー名下部に表示される9桁の数字です。
    フレンド追加数上限は初期状態で10名で、欠片を消費することで拡張が可能です(2023/04/27時点では最大で30名)。
    お互いにフレンド登録をすると、フレンド一覧の名前の横に「MUTUAL」の表示が出ます。
  • なお、この機能は一方通行であるため、相互フレンドになるには相手側の端末でもフレンド追加作業を行う必要があります。
 

プロフィールカード

※ユーザー登録・ログインが必要です。
[画像: プロフィールカード]
※画像内に表示されているデータは架空のものです。

「メインメニュー」>「Network（地球儀のマーク）」>「プロフィール」より、自分のプロフィールカードを表示することができます。

  • ポテンシャル、ユーザー名、ID、クリア状況、現在選択しているパートナーが表示されます。
    • クリア状況は難易度表示をタップすることで「PST → PRS → FTR → ETR→ BYD → PST → ...」の順に切り替わります。
  • カードの背景は選択している情景によって変化します。
  • ユーザー名の背景には選択しているプロフィールプレートが反映されます。
    • ユーザー名および右端の矢印をタップするとプロフィールプレートを選択することができます。
  • 左上にはプリセットに設定しているパートナーが表示されます。
    • 矢印のアイコンをタップするとパートナー選択画面に遷移します。
    • この機能はver6.14.10のパートナー選択機能改修で実装されました。それ以前は「Fracture 光」「Grievous Lady 対立」「天賦第八究明者 識眼」を解禁するとアイコンが表示されていました。
    • また、以前はここをタップすることでストーリーのV-1が再生されていましたが、現在ではこの機能は削除され、専用のページで読むことができます。
 

カスタマイズ

※ユーザー登録・ログインは不要ですが、機能が大幅に制限される可能性があります。

[画像: カスタマイズ]
「メインメニュー」左下にある「変更する」ボタンをタップすることで設定画面に移行。「タイトル画面」「BGM」「情景」の3つを変更できます。

  • ストーリーやワールドモードを進行することにより、項目が解放されていきます。
  • 以前は「情景」のみ変更可能でしたが、ver6.11.0にて「タイトル画面」「BGM」も変更できるようになりました。
  • 右上のボタン2種類を押すことで、それぞれ設定画面やパートナーを非表示にして確認することができます。
    • 左側(長方形のアイコン)：設定画面を非表示にします。「タイトル画面」「BGM」「情景」のいずれを選択していても選択可能です。
    • 左側(初期光のアイコン)：パートナーを非表示にします。「BGM」「情景」を選択しているときのみ選択可能です。

タイトル画面

  • ゲーム起動時のタイトル画面が変化します。今までの大規模なアップデート等で変更されていたタイトル画面の中から、解放されている任意のタイトル画面を設定することができます。ただし、Testify解禁～Last解禁までのタイトル画面のみ存在しません。
    ver6.11.0時点で、ゲームを再起動する以外でタイトル画面を観る手段は存在しません。

BGM

  • ゲーム中のBGMが変化します。メインメニューでのBGMだけでなく、リザルト画面やワールドモードのBGMも変化します。

情景

  • メインメニューの背景、楽曲パック一覧画面のお気に入りタブの背景、プロフィールカードの背景が変化します。情景はワールドモードで解禁することができます。また、入手した情景はArcaea Online内のプロフィール、及びポテンシャル内訳画像の背景に設定することができます。
    情景のみ、Arcaea Onlineから変更することもできます。

クラウド同期

※ユーザー登録・ログインが必要です。
※ver.1.5.0より欠片の所持数の同期はできなくなりました。

楽曲ごとのスコア・解禁済楽曲・ストーリー読破状況の情報をクラウドに保存でき、他デバイスと同期することができます。
同期は自動でなく手動なので、こまめなアップロードをお勧めします。
以下のデータはクラウド同期をしても引き継がれないため、注意が必要です。

  • 入手した欠片
    • ウィンター紅の蓄積分を含む。
  • お気に入り登録した楽曲
  • お気に入り登録したパートナー
  • 各種設定項目
クラウド同期をしなくても引き継がれるデータ

クラウド同期をしなくても引き継がれるデータ

  • 入手したメモリー
  • 購入した楽曲・パック
  • 解禁したパートナー・パートナーレベル
  • ワールドモードの進捗
  • コースモードのクリア状況
  • スタミナ残量
  • ポテンシャル
  • 登録したフレンド・拡張したフレンド枠

[画像: クラウド同期]

[画像: クラウド同期v3.2.3]

  • メインデバイス（画像ではiPad）で「メインメニュー」>「Network（地球儀のマーク）」>「クラウド同期」と進み、データをアップロードします。成功のダイアログが出れば完了です。
    • リザルト画面左上の「同期」からでもデータのアップロードが可能です。
  • 同期先デバイス（画像ではiPhone）で同じく「クラウド同期」に進むと、画像のようなダイアログが表示されます。
    「ダウンロード」をタップするとデータが同期され、「アップロード」をタップするとクラウド上のデータがデバイスのデータに上書きされます。

端末とクラウドでセーブデータが一部食い違う際、引き継ぐセーブデータを選択するダイアログが表示されます。ここでクラウドのデータを使用した場合、端末上のスコアがより低いものに更新される可能性があります（ランキングやポテンシャルなどには影響しません）。

 

言語設定

「メインメニュー」>「More」>「言語」より、アプリ内言語を任意に変更することができます。
選択できるのは以下の5言語です。

  • English / 英語
  • 日本語
  • 한국어 / 韓国語
  • 中文 (繁體) / 中国語 繁体字
  • 中文 (简体) / 中国語 簡体字

全ての言語において各国語のスタッフによるネイティブ翻訳(機械翻訳ではない自然な文章での翻訳)がされています。

  • 楽曲タイトルの中には日本語版でのみ日本語表記となっているものが存在します。
    • 例: 日本語題 -「狂言綺語」
      英題 - False Embellishment
    • このような楽曲は日本語以外の設定では英題表記となります。また日本語設定でも、タイトル順ソートでは英題基準で並び替えが行われます。
  • ギリシャ文字を含むタイトルにはアルファベットに変更されているものが存在します。
    • 「ω4」 → w4
      「γuarδina」→ guardina
      「αterlβus」→ aterlbus
  • 中国語版では「Music Play」の表記が「開始遊戲」となっているなど少々表記が変更されています。
  • コンポーザー・イラストレーター・譜面制作者は、言語に関わらずそのまま表記されます。

Memory Archiveチケットについて

  • 「Memory Archive」の「Beyond以外の全難易度がLevel 9+以下の楽曲」1曲をメモリーを消費せずに入手することができます。
    • どれか1つの難易度でもLevel 10以上の楽曲には使用できません。
      • 例：Distorted Fate（FTRは9でOKだが、ETRは10+なのでNG）
    • Beyond譜面は条件対象外のため、Levelは問いません。
      • 例：Libertas（FTRは9でOK、BYDは10だが条件対象外なのでOK）
    • メモリーを直接消費して購入する以外の方法で入手する楽曲にも使用できません。
      • γuarδina・Désiveなどの楽曲は、ワールドモードで解放する楽曲のため対象外です。
      • Innocenceは上記の通りTier 4コンプリートの報酬であるため、Memory Archiveチケット入手時点で既に入手済みです。
    • 交換可能な楽曲は選曲リスト上にチケットのマークが表示されます。
    • チケットはメモリーよりも優先して使用されます（チケットを残しておいてメモリーで購入することはできません）。

[画像: Settings]

選曲画面上部の「設定」から、ゲームプレイに関わる設定を行うことができます。

設定の一覧

設定の一覧

  • プレイ設定
    • Pure L/E表示
      PURE判定のLATE/EARLYをプレイ中及びリザルト画面で表示するかどうかを選択できます。
    • 譜面速度
      ノーツが流れてくるスピードを調整できます。1.0～6.5まで0.1刻みの56段階で、数字が小さいほど遅く、大きいほど速くなります。基本的にどの譜面も同じ速度で流れてきますが、一部譜面では通常とは異なる速度が設定されているため、適宜ここで自分好みの速さに調整するといいかもしれません。
    • ポテンシャル表示
      画面上部のポテンシャルの表示/非表示を切り替えられま。非表示でも変動はします。
    • スタミナ回復通知
      ワールドモードのスタミナ自動回復が完了した時のプッシュ通知の有無を設定できます。端末本体の設定でArcaeaからの通知を許可しておく必要があります。
    • スキル表示
      楽曲プレイ開始前にパートナースキルの発動を知らせるカットインの表示/非表示を切り替えられます。
    • ポーズ方式
      楽曲プレイ中のポーズボタンの起動方法を「タップ1回」「タップ2回」「長押し」「ボタン非表示」から選べます。
  • 音声設定
    • SE音量
      タップ音などのSEの音量を調整できます。効果音のズレが気になる場合はここで音量をオフ（0%）にするといいでしょう。
      音ズレ調整が+101以上もしくは-101以下（絶対値が101以上）の場合は強制的に0%に変更されます。
    • 音ズレ調整(画像では遅延補正)
      楽曲と譜面のズレを調整できます。端末ごとの目安は遅延調整報告へ。
    • 音声プリセット
      タップすると「スピーカー/有線」「Bluetooth」が交互に切り替わり、SE音量/音ズレ調整を個別に保存しておくことができます。
  • 画面設定
    • 色覚補助モード
      赤色のアークノートが黄緑色に変わり、青色のアークノートも若干青みが強まった色合いになります。対立&トリンのスキルが発動した場合もアークノートはこちらの設定が優先されます。

      FULL RECALL(FR)、PURE MEMORY(PM)の継続中に表示されるマークの表示/非表示、及びその表示位置（楽曲名の下 or コンボ表示の下）を設定できます。

欠片・メモリー

欠片(かけら)とメモリーはArcaeaアプリ内の通貨です。それぞれが異なる入手方法や役割をもっています。

  • 欠片（Fragments）
    欠片は9,999個で1スタックとなり、最大で3スタック（=29,997個）まで貯めることができます。スタックされた欠片は「欠片」欄の下部に白線で表示されます。
    • 以下の用途に使うことができます。
      • 譜面の解禁
      • ワールドモードのスタミナ回復とPlay+、Lost Chapterのブースト
      • フレンド枠の上限解放
      • Link Playでのスタンプの解放
    • 以下の手段から入手できます。
      • 楽曲プレイ(Music Play・ワールドモードのどちらでも)の報酬
      • ワールドモードの報酬タイル(欠片)に設置された報酬
  • メモリー（Memory）
    メモリーには所持数の上限はありません。
    • 以下の用途に使うことができます。
      • 楽曲パック、「Memory Archive」の楽曲の購入
      • ワールドモードのスタミナ回復・メモリーブースト
      • ユーザー名の変更
      • Arcaea Onlineの加入・更新
    • 以下の手段から入手できます。
      • リアルマネーでの購入(アプリ内もしくは公式サイトから)
        ┗公式サイトからの購入はおまけがつきます。クレジットカードが必要です。
        ┗値段はこちらを参照。

その他の機能

  • アカウント管理
    ログアウト、アカウント削除ができます。
    アカウント削除を選択すると登録したメールアドレスに削除確認メールが送られ、承認をするとアカウントが削除されます。

  • コードの利用
    各所で手に入れることができるコードを入力できます。
    なお、ここで各種OSTのシリアルコードを入力すると、Arcaea公式サイトでそれぞれのCDのデジタル音源をダウンロードできるリンクが3回まで生成できます（それぞれの期限は24時間）。

  • ダウンロードの管理
    ダウンロードの管理では、所有している全楽曲のデータをダウンロード(または削除)できます。ここでいう楽曲のデータは音源と譜面のデータを指し、スコアや解禁情報などは含みません。削除しても、一括または個別に再ダウンロードできます。

  • 順位
    トップ200のプレイヤーに限り、プレイヤーアイコンに特殊なフレームが表示されます。
    このフレームには全てのFuture/Eternal/Beyond譜面のスコアを計上した数値を基準とするランクが表示されます。

ルール

曲属性

Arcaeaには「Light(光)」「Conflict(対立)」という2つの曲属性が存在し、ほとんどの楽曲はどちらかの属性に分類されています。

 

難易度・レベル

ArcaeaにはPast / Present / Future / Eternal / Beyondの5つの難易度表記が存在し、それぞれPST / PRS / FTR / ETR / BYDと省略されます。

  • Past / Present / Futureは全ての楽曲に存在します。*7
  • Eternal / Beyondは一部楽曲にどちらか一方が存在し、第4の譜面として別ソートで並びます。
    • Eternal譜面は新たにワールドモードなどで譜面を解禁する必要はありません。
    • Beyond譜面はほとんどの場合、特定の解禁作業(Lost ChapterやBreached Chapterでの解禁等)を経ることで選択できます。解禁作業を終えるまでは一覧に表示されず、レベルも表示されません。*8
    • 全曲フォルダもしくはETR譜面とBYD譜面が混合しているパックを選択した場合、ETR / BYDの難易度をタップする事でどちらをソートするか切り替える事が出来ます。

上記難易度とは別に、すべての譜面には1~7、7+、8、8+、9、9+、10、10+、11、11+、12の全17段階でレベルが割り振られています。

想起率

クリア条件に関わります。PURE/FAR判定で増加し、LOST判定を受けると減少します。詳しくはこぼれ話を参照。
想起率ゲージはパートナーのSKILLによって変化し、3種類に大別できます。詳しい効果はそれぞれの項目を参照。

  • NORMALゲージ
    通常のゲージです。0%からスタートし、楽曲終了時に70%以上でクリアとなります。
  • EASYゲージ
    NORMALゲージよりもLOST時の想起率減少が少ないゲージです。0%からスタートし、楽曲終了時に70%以上でクリアとなります。
  • HARDゲージ
    他のゲージよりクリア条件が厳しくなっています。100%からスタートし、楽曲終了までに0%まで減少した瞬間プレイが終了します。強制終了することなく完走するとクリアとなります。

これらを基本として、パートナーごとに様々なバリエーションがあります。

ノーツ

Arcaeaでは下記5種類のノーツが登場します。

フロアノートロングノートアークノートスカイノートトレースノート
[画像: Floor][画像: Long][画像: Arc][画像: Sky][画像: Trace]
  • フロアノート
    下段を流れるノートです。ラインに重なった瞬間にタップして拾います。
  • ロングノート
    下段を流れるノートです。ラインに重なった瞬間にタップし、ラインを過ぎるまでホールドして拾います。判定は無印PURE/LOSTのみ。
    • ラインを過ぎている途中からでも拾い始めることができます。
    • 途中で離しても直ぐに戻せばコンボは途切れません。この性質を利用して、ロングノートの途中で押している指を入れ替えることができます。
  • アークノート
    上～下段を流れるノートです。ラインを過ぎるまでホールドしながら拾います。判定は無印PURE/LOSTのみ。
    • 青/赤(色覚補助モードは青/黄)の2色があり、基本的にそれぞれ左手/右手を使って拾うと取りやすくなるように設計されています。
    • Past譜面では、必ず第1/第2レーンの間の上空か、第3/第4レーンの間の上空に始点が固定されます。またノートの動きは平行移動のみです。
      Present/Future/Eternal/Beyond譜面では始点が固定されず、さらに上下段レーンの間を自由に動きます。
      • Present譜面では上下移動を知らせるマークが表示されます。
      • ホールドする位置によってレーンが傾きます。
    • ラインを過ぎている途中からでも拾い始めることができます。また、ロングノートとは異なり始点の判定は無いため、あらかじめ指を置いていても拾うことができます。
    • ホールド中に指がずれた場合、少しだけ透明になります。判定点が無い所であれば、直ぐに指を戻せばコンボは途切れません。
      拾っている途中で画面から指を離したり、大きく指がずれた場合、一定時間濃い赤色になり、強制的にLOST判定が出ます。
    • アークノートを一度拾った指は、画面から指を離すまで基本的に同色のアークノートしか拾う事が出来なくなります。
      • アークノート同士が接触している間など、隠された特定のポイントに限り、拾う色を入れ替える事ができるますが、それ以外で異なる指が触れていると、入力無視されている合図としてアークノートは赤く表示されます。
  • スカイノート
    • 上~下段を流れるノートです。トレースノートの先端に重なった瞬間にタップして拾います。
    • 必ず後述のトレースノートに沿って流れてきます(システム上の話であり、譜面によってはトレースノートをごく短くしてスカイノート単独で流れてくるように見せていることもあります)。
    • Present/Future/Eternal/Beyond譜面にのみ出現します。
    • フロアノートと同時押しの場合は青い線で結ばれて流れてきます。また、タイミングはフロアノートと同じ位置の影によっても示されます。
  • アークノート、スカイノート共通
    • Beyond譜面ではFuture以下の譜面よりも上側における可動域が広くなります。
      参考

      [画像: Beyond譜面のアークノート/スカイノート可動域]

      https://twitter.com/ArcaeaWiki/status/1267678079050067969
      • Future譜面でもBeyond譜面の可動域にノーツが出現する楽曲が一部存在します。
        例：Good bye, Merry-Go-Round. (FTR)
      • Eternal譜面では多くの譜面でBeyond譜面の可動域にノーツが出現します。
      • また一部の譜面では、Sky Inputを越えた場所や、この可動域のさらに外側にノーツが出現する場合があります。
        例：UNKNOWN LEVELS (FTR)、Party Vinyl (BYD)、Shades of Light in a Transcendent Realm (BYD)
  • トレースノート
    • 上段～下段を流れるノートです。アークノート/スカイノートの予告やプレイ中の演出に用いられます。操作の必要はなく、判定やスコアには関係ありません。

      • 公開ルームを立てる場合、一度「非公開」でルームを立ててから、ルールの設定で公開設定を「公開」にして下さい。
    • 公開ルームに参加する場合、「公開」を選択すると、ルームの検索が開始されます。
    • 非公開ルームに参加する場合、「Link Play」ウインドウのルームコード入力欄にルームコードを入力してルームに参加します。大文字小文字の区別はされません。
      • そのルームが演奏中だった場合はその旨の表示がされて入ることが出来ません。この場合はしばらく待つ必要があります(1曲は長いものでも3分弱です)。
  • ルールを設定する
    ルームウインドウの左下にある「ルーム設定」では、下記の設定が行えます。
    • ルームの公開設定
      • 「公開」に設定するとランダムマッチ機能でプレイヤーがルームに参加できるようになります。
    • 選曲権
      • 「代表制」では選曲権を持っているプレイヤーが選曲します。選曲権は曲が終了しても移動しません。
      • 「交代制」は代表制と同じく選曲権を持っているプレイヤーが選曲しますが、1曲ごとに選曲権が他のプレイヤーにローテーションされます。
      • 「投票制」では全員が希望楽曲を選び、その中からランダムで決定されます。
        楽曲選択時間になると、「Link Play」ウィンドウ下部に「おまかせ選曲」が表示されるようになり、これを選択した場合は希望楽曲を選択せずに進み、希望楽曲を選択した他のプレイヤーの中からランダムで決定されます。
        全員がおまかせを選択した場合は、選曲可能な全ての曲の中からランダムで決定されます。
      • ルームの公開設定が「公開」になっている場合、選曲権の設定は「投票制」で固定となります。
    • 選曲タイマー
      • オンにした場合、選曲時間に時間制限が設けられます。
      • ルームの公開設定が「公開」になっている場合、選曲タイマーはオンで固定となります。
    • 選曲権を持っているプレイヤーは，各プレイヤーのネームプレート右側にある「⋮」から以下の操作ができます。
      • プレイヤーの強制退出
        任意のプレイヤーを強制退出させることができます。
      • 選曲権をわたす
        選曲権を別のプレイヤーに譲ることができます。
  • プレイの流れ
    • 選曲権が「代表制」または「交代制」の時に選曲権を持っているプレイヤー、選曲権が「投票制」になっている場合は全員、全員が購入・解禁している楽曲に限り、選曲することができます。一人でも購入・解禁していない人がいる楽曲は選曲できません。
      • Link Play中は、通常の楽曲フォルダに加えて「選曲可能」というフォルダが選べます。選べる曲が少ない時などに役に立つフォルダです。
      • 選曲権が「代表制」または「交代制」になっていて選曲権を持っていないプレイヤーは選曲できませんが、楽曲を選択するとその楽曲を「おすすめ」することができます。
    • 選曲権を持っている人が曲を選んだら、確認画面に移行し、全員が「READY」を押したらスタートします。この際、設定とパートナーの変更が可能で、楽曲をダウンロードしていない場合はダウンロードを開始することができます。
    • ハードゲージでTRACK LOSTしたり、難易度ごとに演奏時間が異なる曲を各々が別難易度で演奏しているなどの理由で終了時間が異なる場合、先に演奏が終わった人は他の人が終了するまでしばらく待つことになります。
    • Link Playで楽曲をプレイした場合、欠片を追加で獲得できます。
    • プレイしている全員がFULL RECALL以上またはPURE MEMORYを達成した際、専用の演出が再生されます。
      • リザルトではそれぞれ「LINKED FULL RECALL」「LINKED PURE MEMORY」と表示されます。
    • ルームを退出するときは、ルームウインドウの右上にある「退出する」か、楽曲選択画面の左下にある「中断する」をタップして退出します。

アプリ内課金・楽曲や譜面の解禁

楽曲・パックの購入

※ユーザー登録・ログインが必要です。

Arcaeaでは直接楽曲やパックを購入するのではなく、まずアプリ内通貨のメモリーを購入し、そのメモリーを使って楽曲やパックを購入します。

[画像: Unlock song]

購入したい楽曲(パックの場合はそのパック内のいずれかの楽曲)をタップすることで購入画面が表示されます。

楽曲やパックは次の区分によって分けられます。

  • 「Memory Archive」 : 曲単位で購入可能です。
  • 「Extend Archive」：パック順を参照
  • 「Arcaea」パック : 無料で入手可能です。
  • 「World Extend」：パック順を参照
  • Main Story、Side Story、Collaboration : パック単位で購入可能です。一部パックには「Pack Append」という追加楽曲パックが存在します。
    • パック選択画面のパックの下側にあるPack Appendの欄をタップするか、選曲リストの一番下にある「Appendへ」というボタンをタップすると、Pack Appendの購入画面に移行します。
      ここでパック名か楽曲をタップすることで購入画面が表示されます。購入をやめる場合はリスト最上部の「戻る」ボタンで元の選曲リストへ戻ることができます。
      なお、Appendという名前ではありますが、基本的には元の楽曲パックを購入せず、Pack Appendのみ購入することも可能です。
      • ただし例外として、Lasting Eden Chapter 2のみ、元の楽曲パックであるLasting Edenを先に購入する必要があります。
      また、購入した楽曲は元のパックの選曲リストに統合され、購入時のようにリストを行き来することなく選曲可能になります。

  • ワールドモードでの楽曲の解禁
    [画像: Locked songs]

一部の収録曲はワールドモードを進めることで解禁されます。入手前はアートワーク画像・楽曲欄が半透明になっています。

  • 譜面の解禁
    [画像: Unlock level]

未解禁の譜面には鍵マークがついており、それぞれ解禁に必要な条件が付記されています。
解禁条件の詳細については各楽曲ページの「Requirements」項目を参照。

なお、特定の譜面のクリア/プレイが指定されている場合、上位の譜面でも条件を満たすことができます。

  • 例) Present譜面が指定されている場合、Future/Eternal/Beyond譜面でクリア・同グレードを獲得しても解禁が可能。

  • 欠片???個

    • ワールドモード対象曲や楽曲パックの高難易度曲に多い条件。基本的により簡単な楽曲が指定されますが、「Ether Strike」など例外も存在します。

  • 楽曲 [難易度] をグレード「??」以上で?回クリア
    • Switch版や高難易度曲で登場する条件。Level 11のような高難易度楽曲ではこれら二つが併用されていることがあります。
  • ポテンシャルxx.xx以上を獲得
