Breached Chapterについて ▶
 

Breached Chapterへのアクセスにはポテンシャル値「9.00」以上が必須です。
[画像: Breached Chapter 2]

 

一部の楽曲のみに存在する難易度「Beyond」の解禁マップ専用のチャプターです。実装日時を基準にして並べています。

 
 
  • 凡例
    !Restriction (楽曲制限)
    !Fixed Speed (速度制限)
    ?Random (ランダム)
    +2Stamina (スタミナ)

摂理および有効なパートナー考察

摂理および有効なパートナー考察

TYPE: サポート以外の想起率減少量4倍

  • 1LOSTにつき通常ゲージでは8%、HARDでは20～36%程度減少する。
  • 摂理が進行度に一切干渉しないため、最も効率の良いパートナーは単純にOVER値が高いパートナーになる。詳しくはこちらを参照。スキルやBeyond Challengeにならないパートナーも考慮に入れると、最も効率が良いパートナーはRecall ヴィータ及びWanderer ヴィータである。
  • Fatalis 光の場合、Beyond ChallengeにならないためFAR判定でダメージを受けないが、摂理の影響は受ける(LOST判定のダメージは増加)。Fatalis自身のペナルティの高さから、終盤の1～2LOSTで即死するため安易な選択は危険。安定してFULL RECALLできる譜面を選ぶ必要がある。
  • TYPEが「サポート」のパートナーは数が少ない上OVER値も低く、摂理の影響を受けないパートナーの中で有用なのは「ミール(Lv20 / OVER99)」と「光(Lv30 / OVER71)」くらいしか無いため、特に育ちきったミールが無い限りは摂理を回避する方法は無いものと割り切った方が良い。

摂理および有効なパートナー考察

TYPE: バランス以外の想起率減少量4倍

  • 1LOSTにつき通常ゲージでは8%、HARDでは20～36%程度減少する。
  • 摂理が進行度に一切干渉しないため、最も効率の良いパートナーは単純にOVER値が高いパートナーになる。詳しくはこちらを参照。スキルやBeyond Challengeにならないパートナーも考慮に入れると、最も効率が良いパートナーはRecall ヴィータ及びWanderer ヴィータである。

  • 摂理の影響を受けないパートナーの中でOVER値が高い(90以上)パートナーは以下。特に100以上のサヤやルナはヴィータに匹敵する効率になる。スキル発動時のミカも強力だが、楽曲制限ポイントで使えないのが難。
    • もちろん、TRACK LOSTするリスクの低いパートナーと譜面を選択するなら摂理を完全に無視しても問題ない。

OVER値に応じて、想起率の減少量が肥大

  • Lostによる減少量が(OVER÷40)倍になる。
    • OVERが40を下回る場合は適用されない(最低1倍)。
    • Farによる減少量は変わらない。
    • 【要検証】プレイ中にOVER値が変動するスキルを持つパートナー(Ilith & Ivy、Hikari & Vanessa、千夏)を使った時に即座に減少量に反映されるか
  • 摂理が進行度に一切干渉しないため、最も効率の良いパートナーは単純にOVER値が高いパートナーになる。しかし、OVER値が高いということは摂理によるLOST判定へのペナルティも大きいということであるため、選択には一考を要する。

コメントでの情報提供について

編集はこちらから

Pathについてのコメント欄での情報提供及び編集を行う方は、以下の点に注意いただけるとありがたいです。

 

情報提供者向け

  • 必ずその時点の進行度(%値)を併記してください。
  • 制限がない進行度についての報告も歓迎します。
  • 掲載されている情報と制限内容が異なった場合でも報告していただいて構いません。
    • 内部的な制限設定の位置は小数単位でされていると推測されており、同じ進行度でも制限の内容が異なる報告が多数されています。
  • 解禁を急ぐよりも調査を優先する場合、OVERが低いパートナーの方がより細かく進行度を調査できます。具体的に有効なパートナーを挙げておきます(摂理の介入による増加に注意)。
  • Breached Chapter 1 特有の有用パートナー
    • Tempest 対立：Einherjar Jokerマップなどの摂理影響下1.38%マップにおいて、HARDスキル持ちで1.0%進行ができる貴重なパートナーの一人。Lv8-10で先述のローラーが可能になる。
    • イリス：Tempest 対立同様、Lv12で摂理1.38%マップの1%ローラーが可能。
  • 一般的な有用パートナー
    • 光&フィシカ：OVER0のZero 光を除いてLV20時のOVER値が最低の31です。レベルが低いうちはOVER値がさらに低いので、それを活かした調査ができます。
    • DORO*C：LV30時のOVERが光&フィシカに次いで低い35です。また、強制的にTRACK LOST扱いになるため、実際の成績以上に進行度を低く抑えられます。覚醒前であれば光&フィシカよりも低いOVER値25で、しかもLV1から変わらないので成長を意識する必要もありません。
    • Zero 光：成長するとOVERが低くなっていくので、1%を切るほどでなければ調査に使いやすいです。LV20になるとOVER0で全く進めなくなるため「ランダム選曲ポイントに留まり続けて対象曲を網羅する」という使い方ができますが、その用途なら後述の天々音の方が手軽です。
    • 天々音・マヤ(スキル1)：OVER値が高く使用しての調査には向きませんが、ランダム選曲を無効化するため、ランダム選曲ポイントの候補曲を簡単に調べられます。候補曲だけ調べてすぐに別のパートナーに切り替える運用になります。
