カテゴリについて

  • 「ポップ・おすすめ」
    • サブカルチャー楽曲や東方Projectアレンジ楽曲など、音楽ゲームの経験が浅い方でも触れやすい楽曲のカテゴリです。

    • オリジナル楽曲のうち、パートナー入手(恒常・期間限定問わず)や、覚醒に必要な「核」の入手マップの解放条件となっている楽曲、楽曲の入手マップの解放条件となっている楽曲(MAHOROBA、Floating World、Chromafill、Désive)のカテゴリです。

    • オリジナル楽曲のうち、「パートナー」の条件を満たさない楽曲のカテゴリです。Archive Storyを解禁するために必要な楽曲も含まれます。
  • 「バラエティ」
    • 各コンポーザーやレーベルのアルバムが初出の楽曲やBMS楽曲などが分類されるカテゴリです。
  • 「音楽ゲーム」
    • 他の音楽ゲームから移植された楽曲が分類されるカテゴリです。

入手方法

Memory ArchiveやArcaeaパックのように不定期で楽曲が追加されていきますが、入手方法が2パターンあります。

  • 期間限定マップを踏破する
    • 楽曲のリリースとともに、ワールドモードに期間限定マップが追加され、踏破することで楽曲が無料解放されます。
      • 一部マップはゴールではなくマップ途中に楽曲が配置されており、完走しなくても楽曲解禁が可能です。ゴールには代わりに次元の硝片が配置されています。
    • 解禁マップの復刻開催はありません。
    • Song欄右端の緑色の印は、現在期間限定マップが解放されていることを示しています。印が無い楽曲はマップ解放期間が終了しているため、パックの購入でのみ入手が可能です。
  • パックを購入する
    • メモリーを消費することでこのパックを購入し、マップ解放期間が過ぎた楽曲を含む全てのリリース済み楽曲を入手できます。
    • パック購入後に追加された楽曲もリリースと同時に解放され、すぐにプレイできます。
    • パックを購入した場合も期間限定マップを進めることは可能です。道中のアイテム(欠片・エーテルの雫・次元の硝片)を入手したり、Fatalis 光のステータス強化に充てることができます。
    • パックを購入しても解放期間中に踏破しきれなかった期間限定マップは解放されません。
    • 解禁した楽曲数によってパックの価格が変動します。13曲までは700メモリーですが、14曲目以降は1曲解禁するごとに100メモリーずつ値下げされます(マップを完走する必要はありません)。最終的な収録曲数は20曲なので、買い切った時に解放される曲の単価が最大でも「100メモリー/曲」でとどまるようになっています。
