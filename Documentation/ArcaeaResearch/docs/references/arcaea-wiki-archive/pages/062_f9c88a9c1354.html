スキル詳細(検証中)

スキル詳細(検証中)

  • 1ノーツあたりの想起率上昇量、およびPMを達成した時の想起率は以下の式で計算される（暫定）。 
    譜面の総ノーツ数をNと記載する。

1ノーツあたりのPURE判定時の想起率上昇量(FAR時はこの値の半分)：
70 / (N - 73)

PURE MEMORY達成時の想起率：
N × 70 / (N - 73)
= 70 + 5110 / (N - 73)

※dropdead[PAST]はこの計算式は適用されず、通常の想起率計算式が使用される。
    「総ノーツ数-73」個PURE判定を出すと70ジャスト、つまりLOST判定を73個以内(FARはLOST0.5個分)に抑えればクリアとなる。
    また、「(N - 73) / N * 10,000,000」でクリアに必要なスコアを求めることができる。

調査記録

調査手段

  • このパートナーを設定し、一度も想起率が上限に達しないように、そして一度も想起率が40を下回らないようにプレイする
    • 想起率75を維持することを意識するとやりやすい
  • 最終想起率(R)、ノーツ数(N)、PURE数(P)、FAR数(F)、LOST数(L)を元に、スキルによって減少した想起率を算出する
    • N<400の場合: 100-(R+9*L-(0.2+80/N)*(P+F/2))
    • 400≦N<600の場合: 100-(R+9*L-(0.2+32/N)*(P+F/2))
    • 600≦Nの場合: 100-(R+9*L-(0.08+96/N)*(P+F/2))
    • レベル11以上の場合: 100-(R+9*L-a*(P+F/2))
      • 各曲のaの値は「こぼれ話」の「想起率の仕様」を参照

補足

  • データ通信を切っておくとポテンシャルが下がらない。
  • リザルト画面では想起率の小数点以下が省略されるので、減少量実測値は実際の減少量より0以上1未満だけ大きくなる。
