#35 - Tempest 対立

[画像: Tempest 対立]
英語名 : Tempest Tairitsu
基本バリアント : 対立
楽曲パック「Luminous Sky」「Black Fate」ともに購入後の特定条件で入手可能になるパートナー。

曲のジャケット

曲のジャケット:

  • Tempestissimo
  • Defection
  • Infinite Strife,
  • Pentiment
  • Arcana Eden
スキル詳細

スキル詳細

  • 0になるとTRACK LOSTとなるのは従来のHARDゲージと同様だが、ノーツの判定が想起率に直接は影響しない。
  • スタート時は想起率が時間経過で徐々に減少する状態。
    • PURE/FAR判定は想起率の変化速度をわずかにプラスする。譜面密度や直近のLOST数にもよるが、コンボを繋いでいれば想起率を徐々に回復する状態になる。ただし、譜面が空くと時間経過で少しずつスタート時の速度へと戻っていく。
      • 逆にLOST判定を受けると想起率の変化速度が大きくマイナスされる。回復状態であったとしても、1度でもコンボが切れた瞬間に再び減少が始まるほど。
  • 想起率ゲージは減少中は赤色、回復中は青色になる。均衡時は両色が交互に点滅する。
    • 譜面が終了してもクリア表記が出てリザルト画面に移行するまで想起率の変動は停止しない。
      すなわち譜面終了時点で想起率が残っていたとしても、終了間際にコンボを切ってしまっているとそのまま残ったゲージも尽きて結局TRACK LOSTとなってしまう場合がある。
  • 簡単にまとめるとHARDゲージをベースに想起率の変動量が倍になり、さらに一定時間ごとに減少していくため完走が非常に厳しくなる。このパートナーを使用する際は心してかかる事。
  • ver.5.3.1現在、Lost Chapterで使用した場合に「BEYOND CHALLENGE」扱いにならず(パートナーのカットイン・ゲージに"BEYOND CHALLENGE"の表示がない)、DORO*Cと同様に常時TRACK LOST扱いでパフォーマンスレートが算出されるため注意。
STEP値の仕様

STEP値の仕様
以下の計算式に基づいてSTEP値が算出される。

所持しているパートナーの合計Lv.値/10 + ベース値
※表示される値は小数点以下の端数切捨て

他パートナーのレベル上げを行うことで、Tempest 対立のSTEP値も上がっていく仕組み。合計値にはTempest 対立自身のレベルも含まれる。
手早くSTEPを上げたい場合は全てのパートナーを均等に育成すると良い
パートナーのレベル合計値によるSTEP値増加分の上限は60(レベル合計値にすると600)となっており、それ以上はパートナーのレベルを上げても上がらない(STEP値が赤色になる)。ただし、到達には叶永覚醒実装時点で(ver.5.2.6)最低でも20体(恒常パートナーのみだと26体)のパートナーが必要である。

#56 - Fatalis 光

[画像: Fatalis 光]
英語名 : Fatalis Hikari

曲のジャケット

曲のジャケット:

  • Loveless Dress

スキル詳細

スキル詳細

  • フェイタリスゲージ (Fatalis Gauge)
    • 楽曲演奏中に出したPUREノーツの数だけ想起率ゲージの下限が上昇していく。FARやLOSTでは上昇しない。
      • 楽曲により差はあるが、最終的には最大70%まで下限が上昇する。
      • ゲージの表記数値は下限が上がっても変わらないが、下限に達した瞬間に「0」になってTRACK LOSTとなる。
    • それ以外は通常のHARDゲージと仕様は同じ。しかし、終盤での僅かなミスが致命傷になるため、いわゆるラス殺し譜面とは相性が悪い。
    • ver.4.0.255現在、Lost Chapterで使用した場合に「BEYOND CHALLENGE」扱いにならず(パートナーのカットイン・ゲージに"BEYOND CHALLENGE"の表示がない)、DORO*Cと同様に常時TRACK LOST扱いでパフォーマンスレートが算出されるため注意。
  • スタミナを犠牲にWorld Modeを過負荷状態 (Overload)にする
    • ワールドモードでこのパートナーを使用すると、スタミナを通常の2倍消費する。
      • 通常マップなら4、Lost Chapterなら6、Legacyマップなら2～12消費する。
      • スタミナによるプレイ可否の判定は通常通りのため、スタミナが通常の消費量～Fatalis 光の消費量(2倍)だった場合、スタミナの残量がマイナスになる。
        例えばスタミナ残量が2の時に通常マップをプレイすると、プレイ後のスタミナは-2となる。
      • 消費増加に伴うステップの増加などの効果は、直接的にはない。
    • スタミナを消費したワールドモードで1曲プレイすると、STEP・Beyond進行度を精算した後にWorld Modeが過負荷状態 (Overload)になり、チャプター選択画面まで強制退出させられる。
      • 過負荷状態ではチャプター選択画面で赤い鍵が各チャプターに表示され、そこから先にはアクセスできなくなる。メニュー画面から「続きへ」のショートカットを使用してもチャプター選択画面までしか入れない。
      • Ver4.0.0～4.0.256ではマップを完走した時に本来入れないマップ選択画面に戻される(別のマップを選択するとエラーとなり選択できないので問題はない)不具合があったが、Ver4.1.0で修正された。
      • 過負荷状態は60分間経過、または50メモリー/1,000欠片を使用してのスタミナ回復と同時に解消される。なお、ビギナーミッションの報酬で得られるスタミナでは解除できない。
    • 連続使用が不可能であるため、育成する場合はLegacyマップで大量のスタミナを使う(欠片使用は経験値が増加しない)/メモリーブーストを使うなどできる限りの倍率を乗せる手段を併用するとより効率が良くなる。使用直後にスタミナを回復して即座に過負荷状態を解消したり、マップを走らずにエーテルの雫を使って育成するのも有効。
    • スタミナ消費が倍であるため、通常プレイ1回分のスタミナあたりのSTEP・OVER値の効率は表記値の半分になると考えればよい。このためスタミナに対する効率はSTEPならTempest 対立、OVERなら高OVERのパートナーやAFFINITY (親和度)が高いパートナーよりも劣る。
      しかし、1プレーでの進行量は全パートナー中最大であるため、各種制限マスを回避する、元の高い数値を活かしてブースト効果の使用回数を節約するなどといった使い方が出来る。短いマップならば理論上は1曲プレイだけで完走してしまうことも可能である。
    • 0 Stamina Mapではスタミナ処理は発生しないが、過負荷状態は発生する。STEP値も通常通り算出。
STEP値・OVER値の仕様

STEP値・OVER値の仕様
以下の計算式に基づいてSTEP値・OVER値が算出される。

無限マップを除く踏破したタイルの総数(※期間限定マップを含む) ÷ 30 + ベース値
※表示される値は小数点以下の端数切り捨て
  • 期間限定マップはver.4.0.0以降に新規開催・復刻開催でExtra Chapterに追加されたマップが集計対象となる。
    • ver5.8.0において、ステラ解禁マップ・World Extendなどの1回限定開催マップを除いた過去の期間限定マップ全てが復刻開催され、集計対象になっている。
  • アップデートで削除された常設マップについても、削除までに踏破した分は集計対象から除外されずに有効となる。


    踏破タイル数によるSTEP・OVERへの加算値は100が上限(踏破タイル数に換算すると3,000)で、到達すると数値が赤色になり、それ以上は上がらない。実装時点(ver.4.0.0)では全マップを開拓済みにしても上限まで到達できなかったが、ver.4.1.4にて上限到達可能、ver.6.0.0で恒常マップ全走破で上限到達可能となった。

    全マップの総タイル数とそれによる加算値・最大STEP/OVER値の変遷はこぼれ話を参照。

    • スキル封印状態でプレイしている。
    • Lost ChapterまたはBreached Chapterでプレイしている。
  • 簒奪のパターンは2通り存在する。
    • ① : 楽曲開始時点でIrruptionゲージに変化
      • スキル発動時、カットイン演出とともに「埒外の力が流れ込む―。」*17という文が表示され、簒奪が発生する。
    • ② : Track Lost時点でIrruptionゲージに変化
      • 例 : HARD ゲージ使用時、想起率が0に到達し強制Lostする瞬間、代わりに簒奪が発生し、プレイが続行される。ただし、その後のプレイに関係なくTrack Lost判定となる。
      • 【要検証】HARD持ちでない他のパートナーでも簒奪は発動するか。
  • 簒奪発生時、選択されているパートナーの代わりに本パートナーが強制的に選択される。
    • STEPなどの各種ステータスはラクリミラのものを参照するようになり、経験値もラクリミラが獲得するようになる。
    • Fatalis 光やしゃま等、プレイ前に効果をもたらすパートナーの効果も無効化される。(スタミナは通常通り消費され、欠片も消費されない。)
      • Anomaly特殊演出は元のパートナーに依存する。Lament RainやDesignant.選曲時に簒奪が発動した場合特殊演出は発生しない。
      • ストーリーの解禁条件も元のパートナーに依存する。
      • 例 : ストーリー21-1まで解禁状態で、パートナーにノノカを選択して楽曲「朱月ノ姫」を選曲してクリアしたとき、簒奪が発生していてもストーリー21-2は解禁される。
    • 「メモリーブースト」等の各種ブーストを発動させている場合、ラクリミラのSTEPに対してブーストが掛けられてしまうため、望まないのなら介入を無効化しておくこと。
  • Irruptionゲージ : 楽曲時間で1/4経過時、その時点の想起率を上限値とするHARDゲージに変化する。この時点で想起率が0の場合はTrack Lostとなる。(NORMALゲージ→HARDゲージ)
    • セーレと異なり、ノーツ数ではなく楽曲時間の1/4時点での想起率を参照する関係上、譜面によってゲージ量にバラつきがある。*18普通にプレイしていても50%を超えない事が多いため、Lost1回でも致命傷である。
