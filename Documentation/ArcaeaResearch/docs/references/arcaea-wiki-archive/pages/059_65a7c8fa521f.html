#03 - 紅

[画像: 紅]
英語名 : Kou
楽曲パック「Crimson Solace」の購入で解禁されるパートナー。

  • 読みは「くれない」「べに」ではなく「こう」である。
  • ver.2.4.0において「覚醒 (Awaken)」機能が実装された。
    覚醒には朱の核 25個と空虚の核 5個が必要(ワールドモードにて解禁)。覚醒後はレベル上限が30となり、イラストが変化する他、スキルを獲得する。

バリアント : ウィンター 紅

曲のジャケット

曲のジャケット:

  • Paradise
  • Nirv lucE
  • GLORY：ROAD
  • Diode
  • blue comet
スキル詳細

スキル詳細
以下の計算式で追加の欠片数が算出される。

TRACK LOST：
「プレイ」の値×(スコア-8,000,000)/10,000,000 (最低0)

TRACK COMPLETE以上：
「クリア＋パフォーマンス＋初回クリア」の値×(スコア-8,000,000)/10,000,000 (最低1)

※小数点以下の端数切り捨て

要約すると「800万点を超えた分、10万点で1%増加」となる(端数も考慮される)。
上限の20%には1000万点(事実上PM)が必要だが、端数切り捨てなので多少低くても欠片入手数の上限には到達する。
TRACK COMPLETE以上の場合、どんなにスコアが低くても1は保証される(503万点のTCで1になることを確認)。

スキル詳細(覚醒前)

スキル詳細(覚醒前)

  • Sunset Radianceパック収録曲をプレイした時、通常は楽曲の属性(光・対立)毎に決まっている背景が、属性に関係なく時間帯で変化するようになる。
    • 夜背景(対立)でChelseaをプレイしたり、昼背景(光)でValhalla:0をプレイしたりということができる。
    • Lost Chapterで使用した場合、背景は変わらないが、レーンやノーツの色は変わる。
    • パック収録曲以外に、叶永がアートワークに描かれている曲(緋纏いの宵、彩る夏の恋花火)でも発動する。
  • 時間の区切りは迷える音色は恋の唄のアートワークと同様に、6:00～19:59が昼(光背景)、20:00～5:59が夜(対立背景)。
    • 楽曲プレイ中に切り替わりの時間になっても、プレイ中に背景が入れ替わることはない。
  • 対象曲以外のSunset Radiance背景の楽曲(Heavenly caress、FREEF4LLなど)をプレイしても効果はない。
スキル詳細(覚醒後)

スキル詳細(覚醒後)

  • ワールドモード進行時にSTEPを差し引き貯蓄する。貯蓄されたSTEPは次のワールドモード進行時に追加される。
    • 処理の順番は、パートナーのステータスによるSTEP補正→スタミナ倍率補正→ブースト補正→貯蓄されたステップの加算→獲得したSTEPの貯蓄(減算)。そのため、補正によって貯蓄STEPが増減しない。
  • この効果を利用し、制限マスを回避したり、スタミナマスに止まれたりするよう調節することができる。また、効果はささやかだが期間限定イベント開始前にあらかじめ貯蓄を作っておくこともできる。
  • ウィンター紅やWACCAパートナーと同じように、パートナーやスキルの切り替え、再起動などによる貯蓄のリセットは行われない。
  • 余談だが、1回目はワールドモードが進行しない性質を利用してlegacyチャプターでSTEPを保持→進みたいマップを選び進行することで少ないスタミナでより多く進む事ができる。
    • 数値上はTempest対立のみを使い続けるよりも進めるが、マップやパートナーを切り替える手間がかかる、STEPの微調節やパートナーの育成には使いづらい等デメリットがある。
      • ただしArcaeaOnlineに加入している場合、貯蓄時も僅かに進み続けるので注意。逆にその性質を利用しSTEP16前後のパートナーとして一時的にだが微調節も可能

  • (使用例)プレイ結果が10.0、STEP値が80の場合、本来進行する分の16.0が差し引かれ貯蓄される。この時、ワールドモードは進行せず、次回のプレイ時に追加される。
    • ブーストやPlay +やシンク率の効果は貯蓄されるSTEPに影響しない。上記の例でPlay +のスタミナ×6と欠片ブースト1.5を使用した場合も、貯蓄されるSTEPは16.0で、残りの16.0×6×1.5－16.0 = 128.0が今回の進行に使われる。
    • 次回も覚醒後の叶永を使用しプレイ結果が9.0だった場合、貯蓄された16.0が追加された後に今回獲得した14.4が貯蓄され、最終的なSTEPは16.0になる。次回に別のパートナーを使用した場合、貯蓄したSTEPが単純に加算される。

  • Aegleseeker
  • Seclusion

スキル詳細(検証中)

スキル詳細(検証中)

  • スコアを表示する代わりに、表示時点でのスコアのペースのまま完走した場合に到達するスコアに最も近いグレードと、そのグレードとの差分の数が表示される。
    • なお、PMペースなら内部精度数(無印PURE取得数)がそのまま表示される。そのため、理論値や内部精度を狙う場合に大いに役立つだろう。
      • なおver.3.8.2アップデートで内部精度取得数の表示が無印PURE判定を取った直後に反映されるようになり、タイムラグが無くなった。このため、さらに利便性が上がったと思われる。
  • 予想スコアとペースは以下の式で計算される。 
    精度 = (PURE取得数 + 0.5 FAR取得数) x (Notes so far)/(総ノーツ数)
予想スコア = 現在のスコア + 予想グレードの閾値 x (1 - (Notes so far)/(総ノーツ数))
ペース = 予想スコア - 予想グレードの閾値
    精度予想グレード (グレード閾値)

スキル詳細

スキル詳細

  • 通常/Azureの両方で共通の「階級」ステータスを持ち、通常ノノカで楽曲をクリアするごとに1段階ずつ昇格する。階級の段階によって「獲得欠片数 または World進行度」「想起率減少量」に補正が掛けられる。階級は4段階目(S級/恒星級)が最大。
    • 「プレイ功績に応じて」とあるが、スコアやグレード関係なくクリアの成否によってのみ判定される。
    • Azure時は階級が上下しない。そのため、通常時で昇格させてから覚醒切り替えボタンを押す必要がある。
    • 他のパートナーの使用、アプリの再起動、覚醒切り替え、といった操作を行っても階級はリセットされない。
  • ノノカ使用時にTRACK LOSTする事でペナルティが発生する。
    • 通常ノノカ: 階級なしにリセットされる。
    • Azure ノノカ: World進行度が0になる。階級の降下、その他ステータスや欠片の喪失などのペナルティは起こらない。
      • Music Playなら実質的なペナルティは無いが、スキル自体は発動するため、想起率減少量の補正が適用される点には注意。
