#03 - 紅

[画像: 紅]
英語名 : Kou

  • 「覚醒 (Awaken)」機能が実装されている。
    「朱の核」を30個使用することで覚醒が可能(World Modeにて素材入手)。覚醒後はレベル上限が30となり、イラストが変化する。
スキル詳細

スキル詳細
以下の計算式で追加の欠片数が算出される。

TRACK LOST：
「プレイ」の値×(スコア-8,000,000)/10,000,000 (最低0)

TRACK COMPLETE以上：
「クリア＋パフォーマンス＋初回クリア」の値×(スコア-8,000,000)/10,000,000 (最低1)

※小数点以下の端数切り捨て

要約すると「800万点を超えた分、10万点で1%増加」となる(端数も考慮される)。
上限の20%には1000万点(事実上PM)が必要だが、端数切り捨てなので多少低くても欠片入手数の上限には到達する。
TRACK COMPLETE以上の場合、どんなにスコアが低くても1は保証される(503万点のTCで1になることを確認)。

#08 - エト

[画像: エト]
英語名 : Eto

  • ver.2.0.0において「覚醒 (Awaken)」機能が実装された。
    「双極の核」を30個使用することで覚醒が可能(World Modeにて素材入手)。覚醒後はレベル上限が30となり、イラストが変化する。
    • 双極の核の入手にはDLC「Memory Archive Append 3」の購入が必要。
スキル詳細(覚醒後)

スキル詳細(覚醒後)

  • 通常通りにマップを進んだ結果、マップの報酬として欠片を獲得できる場合にのみ進行度が+7される。
    • 「欠片マスから進む」場合は無効で、「欠片マスに到達する(または通過する)」場合に進行度+7が発動する。
    • 楽曲のプレイで獲得した欠片では+7されない。
  • 計算順は、プレイの結果によるステップ値→パートナーのSTEP値による乗算→パートナースキル(+7)の順。進行度ボーナスは最後に適用され、STEP値の影響は受けない。

#15 - 叶永

[画像: 叶永]
英語名 : Kanae

スキル詳細

スキル詳細

  • 「Sunset Radiance」パック収録曲をプレイした時、通常は楽曲の属性(光・対立)で変化する背景が、楽曲に関係なく時間帯で変化するようになる。
    • 夜背景(対立)でChelseaをプレイしたり、昼背景(光)でValhalla:0をプレイしたりということができる。
    • パック収録曲以外に、叶永がアートワークに描かれている曲(彩る夏の恋花火)でも発動する。
  • 時間の区切りは迷える音色は恋の唄のアートワークと同様に6:00～19:59が昼(光背景)、20:00～5:59が夜(対立背景)となっている。
    • 楽曲プレイ中に切り替わりの時間になっても、プレイ中に背景が入れ替わることはない。
  • パック収録曲以外のSunset Radiance背景を使用している楽曲(Heavenly caress、FREEF4LLなど)をプレイしても効果はない。

#17 - Tempest 対立

[画像: Tempest 対立]
英語名 : Tempest Tairitsu

スキル詳細

スキル詳細

  • 時間経過に伴い一定の速度で想起率が減少し続け、0になったらTRACK LOSTとなる。
  • LOST判定を受けると想起率を下に引っ張るおもりがついたような状態になり、時間経過による減少に拍車をかける形になる。LOST判定が連なるとそのおもりの重さが加速度的に増加し、減少スピードがみるみる上がっていく。
  • 逆にPURE/FAR判定は上に引っ張り続ける浮力のような影響を想起率にもたらす。こちらも判定を連ねることでその影響が強まるので、減少に抗い、さらには短時間ではあるものの時間経過で上昇し続ける状態にまで転じさせることができる。
  • 想起率ゲージは減少傾向時に赤色、上昇傾向時に青色になり、均衡時は両色が交互に点滅する。
  • 譜面が終了してもクリア表記が出てリザルト画面に移行するまで想起率の変動は停止しない。すなわち譜面終了時点で想起率が残っていたとしても、それが減少傾向にあればそのまま0に到達し、結果としてTRACK LOSTとなってしまう場合がある。
STEP値の仕様

STEP値について
以下の計算式に基づいてSTEP値が算出される。

所持しているパートナーの合計Lv.値/10 + ベース値
※表示される値は小数点以下の端数切捨て

他パートナーのレベル上げを行うことで、Tempest 対立のSTEP値も上がっていく仕組み。合計値にはTempest 対立自身のレベルも含まれる。
パートナーのレベル合計値による増分の上限は400(STEP値にするとベース値+40)に設定されており、それ以上はパートナーのレベルを上げても上がらない(STEP値が赤色になる)。

有料コンテンツも購入し20体のパートナーをLv.20にするか、
有料コンテンツを購入しない場合は、5体いる覚醒パートナー(光/対立/紅/レーテー/調)の内4体を覚醒させ、全てのパートナーをLv.20(覚醒はLv.30)にする必要がある(ver.1.2.1現在)。
ベース値は下表「レベルとステータス」を参照。

スキル詳細

スキル詳細

  • フェイタリスゲージ (Fatalis Gauge)
    • 楽曲演奏中に出したPUREノーツの数だけ想起率ゲージの下限が上昇していく。FARやLOSTでは上昇しない。
      • 楽曲により差はあるが、最終的には最大70%まで下限が上昇する。
      • ゲージの表記数値は下限が上がっても変わらないが、下限に達した瞬間に「0」になってTRACK LOSTとなる。
    • それ以外は通常のHARDゲージと仕様は同じ。しかし、終盤での僅かなミスが致命傷になるため、いわゆるラス殺し譜面とは相性が悪い。
  • World Modeを過負荷状態 (Overload)にする
    • ワールドモードで1曲プレイすると、STEPを精算した後にWorld Modeが過負荷状態 (Overload)になり、チャプター選択画面まで強制退出させられる。
      • 過負荷状態ではチャプター選択画面で赤い鍵が各チャプターに表示され、そこから先にはアクセスできなくなる。メニュー画面から「続きへ」のショートカットを使用してもチャプター選択画面までしか入れない。
      • Switch版はスタミナ制ではないため、過負荷状態の解消条件が「通常モード(Music Play)で1曲クリアする」に変更されている。
