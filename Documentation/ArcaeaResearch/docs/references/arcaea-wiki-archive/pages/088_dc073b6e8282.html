(58*1)
 
  • 報酬に天賦第八究明者 慈哀のアイコンが表示されているものの、実際には隠し楽曲「Designant.」が解禁できる。
    • パートナーはこのマップで解禁することができず、別のマップが用意されている。
  • このマップではパートナーに関わらずゲージの種類が固定される。また、各種ブーストは使用できず、プレイによるパートナーexpは獲得できない。特殊な進み方をするマップである。
  • 楽曲「Designant.」を任意の難易度で解禁するとこのマップは非表示になる。
 
進行方法

進行方法
～ Map 1 / TILE 14

  • 通常のマップと同様にマップを進める。
  • TILE 15の石板マスに到達すると、通常のプレイではマップが一切進行しなくなる。
    これ以降は、特殊な方法でマップを進行する。
    • 次のマスに進めない場合、タイルが赤く光る。

Map 1 / TILE 15

  • Story Modeメニュー画面下部にあるボタンからパートナー選択画面へ移動し、天賦第八究明者 慈哀のイラスト(アイコンではない)を長押しし、イラストが変化することを確認する。
  • この状態で楽曲を完走すると、TILE 19まで進む。
  • 完全放置してTRACK LOSTでも問題なく進む。

Map 1 / TILE 19 ～ Map 3 / TILE 200

  • NORMALゲージで楽曲を完走することで進行する。
  • 完全放置してTRACK LOSTでも問題なく進む。
  • 割れた石板マスに止まると、別のマップに移動する。

Map 4 / TILE 65 ～ TILE 13

  • Map 4から、プレイ中のゲージはHARDゲージで固定されるようになる。
  • また、進む先は通常とは逆向き、つまり下向きであり、まるで落ちていくような挙動を示す。
    天賦第八究明者 慈哀はTILE 78におり、慈哀から逃げるような形になる。
  • HARDゲージで想起率を0にし、楽曲をTRACK LOSTすることで進行する。

Map 4 / TILE 0

  • Lament Rainの楽曲制限マス。このマスで楽曲解禁を行う。
  • Designant.に移行したい難易度でLament Rainをプレイする。
  • Lament Rainのアウトロに入ると、Sky Input中央に心電図のような赤いトレースが出現する。
  • 赤いトレースが震えるタイミングで透明なノーツがあるので、それに合わせて叩く。このとき、透明ノーツのPURE/FAR判定を3つ以上獲得することが移行条件となる。
    • 透明のノーツ以外は移行の判定に影響しないので、透明のノーツだけを叩いてもよい。
  • 移行条件を満たすとDesignant.に移行し、そのまま完走すると解禁となる。
  • Testify解禁後、天賦第八究明者 識眼をLv.20にして正式にパートナーに指定できるようになってからスキルロックした状態でLament Rainをプレイすると、上記演出を再発生させることができる。
